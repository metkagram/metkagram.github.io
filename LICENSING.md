# Metkagram licensing and rights

Effective from 17 August 2026.

Metkagram is **publicly inspectable, but not open source and not open data by default**. The public repository exists so the project can be read, cited, evaluated, and operated transparently. Publication is not a blanket permission to copy the project into another product or corpus.

The root [LICENSE](LICENSE) is the controlling repository notice. This page is a practical summary, not a replacement for it.

## Rights map

| Material | Default position | What is allowed without asking |
|---|---|---|
| Hosted website | Public end-user access | Read, learn, link, cite |
| Source code | All rights reserved unless a file says otherwise | Inspect on GitHub; use the hosted site |

| Pattern collections and examples | All rights reserved for new revisions | Read, link, cite; prior CC releases retain prior grants |

## Ask first for

Written permission is required unless applicable law independently permits the use:

- substantial copying, scraping, mirroring, or redistribution;
- derived corpora, pattern libraries, or annotation datasets;
- model training or fine-tuning on substantial Metkagram material;
- production RAG/retrieval corpora built from substantial Metkagram material;
- commercial benchmark or evaluation datasets;
- commercial/API/product integrations;
- redistribution of modified source code or a substantially derived implementation;
- use that removes Metkagram provenance or makes the material appear to originate elsewhere.

## Research is welcome, but proposal-first

The project is deliberately open to serious research. A researcher can cite and discuss Metkagram without asking. If a study needs a local corpus copy, redistributed stimuli, derived annotations, model training, publication supplements, or other substantial reuse, request a scoped research permission first.

A useful request contains:

1. person, institution, or company;
2. research question or product goal;
3. exact datasets, routes, or components needed;
4. whether material will be copied, redistributed, transformed, or used with models;
5. expected outputs and publication plan;
6. commercial or non-commercial context;
7. proposed Metkagram attribution.

See [docs/RESEARCH_USE.md](docs/RESEARCH_USE.md).

## Available arrangements

Metkagram may grant separate written terms for:

- academic and supervised research;
- classroom or institutional teaching;
- corpus and annotation evaluation;
- commercial language-data use;
- API or agent integration;
- product embedding;
- joint experiments and publications;
- strategic or investment partnerships.

A permission can be narrow: one dataset, one experiment, one publication, one product, a defined period, or a defined number of users. Public access therefore does not require giving every future use the same rights.

## Attribution

A compact citation is (canonical form generated from `src/release.mjs`):

> Kharlanau, D. (2026). *Metkagram: Visual Language Patterns and Annotated Learning Resources* (version 1.0.0) [Dataset]. https://metkagram.github.io/

When a specific record is used, retain its canonical Metkagram URL and dataset/version metadata where available.

## Earlier CC BY-NC 4.0 material

Before 17 August 2026 the repository was offered under CC BY-NC 4.0. That license is not retroactively revoked for copies obtained under those terms. The current notice governs new revisions and newly introduced material unless an explicit file-level notice states otherwise.

This distinction is intentional: version history stays honest while future work is no longer automatically licensed for copying and adaptation.

## Public GitHub repository

GitHub's Terms of Service give GitHub and GitHub users limited platform rights needed to host, display, and fork public repositories. Those platform permissions do not mean Metkagram grants a general open-source or open-data license outside the rights stated in the repository notice.
