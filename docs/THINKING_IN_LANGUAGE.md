# Thinking in Language

Status: curriculum extension in active review.

Metkagram can teach more than isolated grammar forms. A reusable Frame can also preserve a useful reasoning operation: frame a problem, separate evidence from assumptions, trace system effects, or make a decision under uncertainty.

The first Thinking in Language extension adds four B2–C1 study sets without replacing or removing any existing curriculum:

- **FRM — Problem framing and reframing**: define the problem, expose the constraint, and choose a more useful frame before solving.
- **UNC — Reasoning under uncertainty**: separate evidence from assumptions, calibrate confidence, and ask for discriminating evidence.
- **SYS — Systems thinking**: trace second-order effects, bottlenecks, local optimisation, symptoms, and structural drivers.
- **DEC — Decision quality and trade-offs**: set criteria first, use reversibility, compare the cost of delay, distinguish risk profiles, and preserve optionality.

Each set starts with five curated English/German Frames, Russian learner-support translations, examples, and reasoning metadata. The content is additive: existing study sets remain part of the public curriculum.

## Editorial rule

A thinking Frame belongs here only when it does two jobs at once:

1. it is a natural, reusable language pattern worth learning at B2–C1;
2. it encodes a reasoning operation that a learner can reuse in another situation.

The goal is not to turn Metkagram into a philosophy glossary. The learner should be able to say the pattern in a meeting, an essay, a technical discussion, or an ordinary decision and immediately gain a clearer way to structure the thought.

## Next expansion candidates

Future reviewed sets can cover causal diagnosis, hypothesis testing, perspective taking, learning from mistakes, strategic sequencing, and metacognitive language. New sets should extend the curriculum rather than consolidate it by deletion.
