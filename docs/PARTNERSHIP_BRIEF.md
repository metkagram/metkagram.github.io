# Metkagram partnership brief

## Thesis

Metkagram is a research-oriented language-pattern system built around one durable asset: reviewed relationships between real sentences, reusable B2–C1 patterns, communicative and reasoning moves, examples, translations and provenance.

The public product follows a simple loop:

> **real language → visible structure → reusable pattern → contrast → choice → reasoning route → practice → reuse**

The same stable learning objects support three surfaces:

- a readable learning interface for people;
- a machine-readable reference layer for tutors, agents, researchers and language tooling;
- portable reviewed exports for teachers, tutors and pilot integrations.

Metkagram does not try to replace a general AI tutor. The project supplies a reviewed pattern layer that an AI tutor, teacher or learner can reuse.

## Current public release

The current public boundary is deliberate and recorded in `data/publication-manifest.json`.

It includes:

- the established 1,000+ English/German B2–C1 Practice curriculum;
- 72 selected annotated documents, 12 from each published English/German collection;
- 30 reasoning-enabled frames across 9 reasoning moves;
- study sets and learning paths over stable pattern IDs;
- Pattern Lens, Pattern Atlas, Pattern Graph and the active practice loop;
- 9 reviewed Contrast Library pairs and 18 two-sided Pattern Choice Clinic drills;
- 5 reviewed Reasoning Packs built from canonical patterns, contrasts and drills;
- a derived Pattern Relation Index that connects Lens matches to reviewed next steps;
- generated teacher/tutor exports for each Reasoning Pack in JSON, CSV and study-friendly TSV;
- public evaluation fixtures over deliberately released material;
- static datasets, OpenAPI, search resources and read-only agent manifests.

The private research core retains the full annotated corpus, bulk annotation/model-preparation exports, the spaCy annotation engine, linguistic heuristics and lexical rules, generation machinery, participant data and unpublished research work.

These are content and infrastructure facts, not audience, revenue or language-learning efficacy metrics.

## Why the asset can compound

### 1. The graph matters more than the page count

A pattern becomes more valuable when it is connected to the job it performs, nearby alternatives, reviewed distinctions, deliberate-choice practice, reasoning routes, examples and provenance. The long-term asset is a Language Pattern Knowledge Graph rather than a flat phrase list.

### 2. One reviewed object can travel

The same stable pattern ID can appear in Pattern Lens, an Atlas topic, a contrast, a practice queue, a Reasoning Pack, a teacher export or an AI-tutor answer without creating competing definitions.

### 3. Static public delivery keeps the core cheap

The website and machine-readable reference layer are generated as reproducible static artifacts. Expensive NLP and high-recall annotation can remain a separate private or licensed service rather than becoming a runtime dependency for every visitor.

### 4. Partners can test reuse before asking for integration

A teacher, school or EdTech team can now take one reviewed Reasoning Pack into an existing workflow using JSON, CSV or TSV while preserving stable IDs, canonical links and attribution. That produces concrete feedback before either side commits to a larger integration.

## Near-term partnership packages

### 1. Method validation

Deliverables: preregistration, reviewed stimuli, pilot execution, analysis code and a public report.

Success measure: a completed and reproducible comparison study, regardless of whether the result is positive, null or negative.

### 2. Editorial and linguistic review

Deliverables: annotation sample design, independent review, adjudication workflow, contrast review and regression fixtures.

Success measure: documented agreement and correction rates for the reviewed sample.

### 3. Teacher-curated pattern pack

Deliverables: one focused B2–C1 Reasoning Pack, reviewed examples and contrasts, two-sided choice drills, portable JSON/CSV/TSV export and canonical attribution.

Success measure: the pack is used in a real teaching workflow and produces concrete editorial feedback on sequence, explanations and export usefulness.

### 4. AI tutor / EdTech integration

Deliverables: read-only intent, pattern, related-pattern, contrast, choice-drill, reasoning-pack and export retrieval using stable IDs and provenance.

Success measure: an external tutor can resolve a learner job to a small reviewed route instead of generating an unbounded phrase list, and can reuse the same canonical objects as the public website.

### 5. Licensed annotation pilot

Deliverables: a bounded batch of partner text processed by the private annotation/retrieval pipeline with agreed output fields and quality checks.

Success measure: the output is useful enough to justify a larger scoped integration without exposing the private engine.

## Partnership models

- Research collaboration with preregistration and publication independence.
- Teacher or language-school co-curation with explicit contribution provenance.
- EdTech / AI-tutor integration using the public reference layer or a scoped licensed service.
- Linguistic or editorial contribution with named review credit where appropriate.
- Commercial licensing for substantial reuse, redistribution, annotation services or protected research assets.
- Mission-aligned funding tied to a concrete milestone package rather than vague project sponsorship.
